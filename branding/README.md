# Logo WaspadAI

Letakkan satu file logo utama di folder ini dengan nama persis:

`waspadai_logo.png`

Spesifikasi yang disarankan:

- PNG persegi, idealnya 1024 x 1024 piksel.
- Latar transparan.
- Logo utama berada di tengah.
- Sisakan ruang aman transparan sekitar 15-20% pada setiap sisi agar logo tidak terpotong ketika ditampilkan sebagai ikon bulat atau adaptive icon Android.
- Jangan mengganti nama file dan jangan menambahkan versi lain ke folder ini.

File sumber tunggal ini akan dipakai untuk:

1. ikon utama aplikasi Android;
2. ikon pada bubble overlay Tanya Area;
3. logo pada header halaman Verifikasi.
